# 🎨 Color Hunt Game

A multi-level, GUI-based color identification game built in Java as part of the Object-Oriented Programming course at FAST-NUCES Karachi.

## About

Color Hunt challenges players to identify the **color of text**, not what the word says — training focus and quick thinking. The game features increasing difficulty, sound effects, score tracking, and a surprise mini-game mechanic.

## Features

- **Two game modes** — Classic and Challenge (faster, harder)
- **Score tracking** with persistent high-score saved to file
- **Lives system** — lose 3 in a row and a Tic-Tac-Toe mini-game gives you a second chance
- **Background music** (Pink Panther theme) with mute toggle
- **Sound effects** on button clicks
- **Colorful, modern UI** built with Java Swing — gradient buttons, dynamic backgrounds

## Tech Stack

- Java
- Java Swing (GUI)
- OOP principles — Encapsulation, Inheritance, Abstraction, Polymorphism
- File handling for persistent score storage

## OOP Concepts Applied

| Concept | Where Used |
|---------|-----------|
| Encapsulation | Game state, player data, score management |
| Inheritance | Game mode classes extending base game |
| Abstraction | Abstract game logic separated from UI |
| Polymorphism | Different game modes with shared interface |
